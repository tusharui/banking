Banking Fraud Detection System

A real-time transaction fraud detection web app built with Streamlit and scikit-learn. It predicts whether a banking transaction is fraudulent or legitimate and shows an intuitive probability bar along with risk levels.

Features

✅ Real-time fraud prediction for individual transactions

📊 Shows fraud probability, risk level, and verdict

🟢🟡🔴 Color-coded LOW / MEDIUM / HIGH risk

🔬 Displays engineered features for debugging

🖥️ Easy-to-use responsive Streamlit UI

💾 Supports saved models with optional scaler
